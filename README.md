# FastChat — демо-мессенджер (C++ + HTML/CSS)

Простой учебный проект: чат-сервер на C++ (сырые POSIX-сокеты / Winsock,
без внешних библиотек — SHA1, Base64 и минимальный JSON написаны вручную)
и веб-клиент на HTML/CSS/JS с интерфейсом в стиле Telegram.

## Функционал

- Обычные текстовые сообщения (мгновенная доставка через WebSocket)
- 😀 Эмодзи-пикер в поле ввода
- Реакции на сообщения (клик по значку 🙂 у сообщения → выбор эмодзи, счётчик и тоггл при повторном клике)
- 📎 Отправка файлов и картинок в общем чате — картинки показываются превью прямо в чате (клик открывает полноразмерный просмотр), остальные файлы — карточкой с кнопкой скачать
- ✏️ Редактирование и 🗑 удаление своих сообщений (доступно через «⋮» при наведении на своё сообщение)
- «Печатает…» — статус набора текста у собеседника в шапке чата
- 🔔 Звуковое уведомление о новых сообщениях (можно выключить кнопкой в сайдбаре) и счётчик непрочитанных в заголовке вкладки браузера, пока она не активна
- 🌙/☀️ Переключатель тёмной/светлой темы
- Список контактов (кто сейчас в сети) с переходом к последнему сообщению собеседника
- 📞🎥 Аудио- и видеозвонки один-на-один (WebRTC): кнопки звонка появляются при наведении на контакт в сайдбаре; входящий звонок показывает экран принять/отклонить с «пульсирующей» аватаркой; во время звонка доступны мьют микрофона, выключение камеры (для видеозвонка) и завершение звонка с таймером разговора
- 💬 Личные сообщения (ЛС) — клик по контакту в сайдбаре открывает отдельную переписку один-на-один с ним (не видна остальным участникам чата); есть свой статус «печатает…», индикатор непрочитанных сообщений (бейдж на контакте) и переключение между «Общим чатом» и открытыми ЛС одним кликом

## Как устроены ЛС

Личные сообщения используют тот же WebSocket-канал, что и общий чат, но
сервер пересылает их **только двум участникам переписки**, а не всем
подключённым (в отличие от обычных сообщений в общем чате, которые
рассылаются broadcast). Это касается и текста, и **отправки файлов/картинок**
из ЛС — они тоже уходят только собеседнику. История ЛС хранится только в
браузере на время сессии — как и общий чат, она не переживает перезагрузку
страницы.

**Известное ограничение:** реакции и редактирование/удаление сообщений
технически рассылаются всем подключённым (broadcast), даже если исходное
сообщение было в ЛС — сторонние клиенты просто не найдут такой id в своём
локальном списке сообщений и ничего не покажут, но с точки зрения протокола
это не идеально приватно.

## Как устроены звонки

Голос и видео идут напрямую между браузерами по протоколу WebRTC (peer-to-peer,
без прохождения через сервер) — сервер участвует только в **сигнализации**:
пересылает предложение (offer), ответ (answer) и ICE-кандидаты от одного
конкретного пользователя к другому по имени, не рассылая их всем (в отличие
от обычных сообщений чата). Для обхода NAT используется публичный STUN-сервер
Google (`stun.l.google.com`) — для этого нужен доступ в интернет; в полностью
изолированной локальной сети без выхода наружу STUN не обязателен, если оба
компьютера в одной подсети (тогда сработают локальные ICE-кандидаты).

## Файлы

- `server.cpp` — сервер для **Linux/macOS** (POSIX-сокеты).
- `server_windows.cpp` — тот же сервер, но для **Windows** (Winsock2),
  без WSL и без Linux — компилируется напрямую в `.exe`.
- `server.exe` — уже собранный Windows-сервер, готовый к запуску без установки компилятора.
- `client.html` — открой в браузере. Указываешь имя, дальше —
  обычный чат с сообщениями-«пузырями» в стиле Telegram.
- `start_server.bat` — запускает `server.exe` и открывает `client.html` одним кликом.

## Сборка на Linux / macOS

```bash
g++ -std=c++17 -pthread server.cpp -o server
./server 9001
```

## Сборка на Windows (напрямую, без WSL)

Готовый `server.exe` уже собран и не требует компиляции — просто запусти его
или дважды кликни `start_server.bat`. Если хочешь собрать сам:

### Вариант A — MinGW-w64

```powershell
g++ -std=c++17 server_windows.cpp -o server.exe -lws2_32
server.exe 9001
```

### Вариант B — Visual Studio (MSVC)

```powershell
cl /std:c++17 /EHsc server_windows.cpp /link ws2_32.lib
server_windows.exe 9001
```

По умолчанию порт 9001, можно указать любой свободный порт первым аргументом.

## Использование

1. Запусти сервер или дважды кликни `start_server.bat`.
2. Открой `client.html` в браузере (можно в двух вкладках — как два разных пользователя).
3. Укажи `ws://localhost:9001`, введи имя, нажми «Войти».
4. Клик по контакту в сайдбаре открывает личную переписку с ним.
5. Кнопки звонка (📞/🎥) на контакте запускают аудио- или видеозвонок.

## Ограничения (учебная версия, не продакшен)

- Нет шифрования (`ws://`, не `wss://`).
- Нет базы данных — история сообщений не сохраняется между перезапусками.
- Нет авторизации/паролей — имя ничем не защищено, два человека могут войти под одинаковым именем.
- Файлы ограничены ~8 МБ на клиенте / 25 МБ на сервере.
- Файлы, реакции, редактирование/удаление — только в общем чате, не в ЛС.
